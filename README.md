# Portfolio

My personal portfolio website, built with Next.js, TypeScript, and Tailwind CSS.

🔗 **Live site:** [shahulportfoliohere](https://shahulportfolio.vercel.app/)

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS

## Getting Started

```bash
git clone https://github.com/kattziee/Portfolio.git
cd Portfolio
npm install
npm run dev
```
